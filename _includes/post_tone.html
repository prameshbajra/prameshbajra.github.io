{%- comment -%} Assigns `tone` (string) for a post's tag pill. Usage: {% include post_tone.html post=post %} → then {{ tone }} The post's first tag is its primary topic, so the pill just resolves that slug against _data/topics.yml rather than re-deriving it from keywords. {%- endcomment -%} {%- assign tone = "Notes" -%} {%- assign primary = include.post.tags | first -%} {%- for topic in site.data.topics -%} {%- if topic.slug == primary -%} {%- assign tone = topic.label -%} {%- break -%} {%- endif -%} {%- endfor -%}
